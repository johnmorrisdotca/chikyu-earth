パッケージは 0.x なので、マイナーバージョン (0.5 から 0.6 など) で動きが変わることがあります。各リリースの内容は [変更履歴](../../../CHANGELOG.md) にあります。このページには、対応が必要なことだけを書きます。

## 0.18 へ: どの表示も自分でズームし、回ります

`<chikyu-earth>`、`<chikyu-earth-realistic>`、`<chikyu-space>` が kazoku-ui の操作 (ドラッグ、ピンチ、Ctrl とホイール、キー) を持つようになりました。これまで何もつないでいなかったページでも、操作できるようになります。「全体」でのふつうのホイールは、これまでどおりページをスクロールします。次のときは対応してください。

- 要素を囲むラッパーに `<kazoku-view-controls for="...">` を付けている: `for` を要素そのものに向けてください (要素に `id` と `tabindex` を付けます)。または要素に `controls="none"` を付けてください。そうしないと、ドラッグが 2 回処理されます。
- 操作が要らない (サムネイルや背景): `controls="none"` を付けてください。
- 範囲を保つために、バーに `zoom-min` と `zoom-max` を付けている: 要素自身の範囲は、line が 0.1 から 20、リアルが 0.1 から 5 (タイルがあれば 20)、space が 100 万分の 1 から 2.5 になりました。バーの属性は、これまでどおり優先されます。[ズーム、移動、回転](zoom-and-pan.md)を見てください。
- kazoku-ui を入れずに使っている: 要素が `view-controls` を読み込むため、kazoku-ui は依存関係になりました (これまでは、なくてもよい peer でした)。

埋め込みページ (`embed.html`) は、初期状態で操作できるようになりました。すでに使っている iframe も、ドラッグや拡大縮小ができます (「全体」でのふつうのホイールは、これまでどおりあなたのページをスクロールします)。静止した絵にしたいときは、アドレスに `hands=0` を付けてください。`turn=auto` は今までどおり自動で回ります。`turn=1` は今も使えますが、何も変わりません。

## 0.9 へ: いっしょに動く機能と、静かになった自動回転

新機能: `element.ride(...)` と `ridePose` (`/space` にあります)。気づくかもしれない変更が1つあります。`<chikyu-space>` の `setView(view, final = true)` に、2つ目の引数が付きました。共有コントロールの `detail.final` を渡すと (デモはそうしています)、地球と同じ速さの自動回転が、1秒に30回描くことをやめます。何も渡さなければ、これまでどおり、変わるたびに描きます。

## 0.8 へ: 人工衛星

新しい任意のエントリーポイント `/satellites` (計算部分) と、`<chikyu-space>` の新しいメソッド (`setSatellites` など) が加わりました。`satellite.js` (バージョン6) は任意の依存パッケージなので、人工衛星を使うときだけ入れてください。今あるものは変わりません。デモの宇宙のコントロールと、埋め込みの `look=space` は新機能です。

## 0.7 へ: `look` 属性

`<chikyu-earth look="thick">` は、`style` 属性の新しい名前です。普通の HTML では `style="thick"` も今までどおり動くので、壊れるものはありません。React、Vue、Angular では `style` が CSS として読まれて動かないので、そこでは `look` を使ってください。

## 0.6 へ: 太陽、月、惑星

新しい任意のエントリーポイント `/space` (計算部分) と `/space/element` (`<chikyu-space>`) が加わりました。`astronomy-engine` は任意の依存パッケージで、宇宙の表示を使うときだけ入れます。平面の地球儀とリアルな地球は変わっていません。

## 0.5 へ: リアルな地球と目印

新しいエントリーポイント `/realistic`、`/realistic/element`、`/markers` が加わりました。平面の地球儀は変わっていません。`three` と `@johnmorrisdotca/kazoku-ui` は任意の依存パッケージで、リアルな地球を使うときだけ入れます。

## 0.4 へ: chizu の輪郭

輪郭、名前、コードは `@johnmorrisdotca/chizu/world-geo` から来ます。177 か国で、コードのない3か所は `alpha2` が null です。`COUNTRIES` を使っているコードは、新しい数を想定してください。
