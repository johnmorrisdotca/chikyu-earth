`<chikyu-space>` は、選んだ人工衛星から真下の地面へ、やわらかい光のビームを描けます。指定するまでは表示されません。選んだ人工衛星とは、`selectSatellite`（またはその衛星を押したとき）で印をつけた衛星、または乗っている衛星です。

```html
<chikyu-space look="space" beam beam-cells="19" style="width: 420px"></chikyu-space>
```

```ts no-run
import type { ChikyuSpace } from "@johnmorrisdotca/chikyu-earth/space/element";

const space = document.querySelector<ChikyuSpace>("chikyu-space")!;
space.selectSatellite({ group: "stations", index: 0 });
space.beam = true;
console.log(space.stats.beam.radiusKm);
```

| 属性 | プロパティ | 意味 |
|---|---|---|
| `beam` | `beam` | 選んだ衛星のビーム。なし（または `beam="off"`）なら出ません。値なしの属性か `beam="selected"` で出ます。 |
| `beam-elevation` | `beamElevation` | 衛星が見えるとみなす最低の仰角（度）。省略すると 25、範囲は 0 から 80。 |
| `beam-cells` | `beamCells` | 光の輪の中に描くスポットセルの数。省略すると 0、最大 91。 |
| `beam-cell-size` | `beamCellSize` | セル 1 つの地上での半径（km）。収まる大きさまで。省略すると 0（収まる大きさ）。 |
| `beam-color` | `beamColor` | ビームの色。CSS の色ならどれでも。省略すると淡い青。 |
| `beam-strength` | `beamStrength` | ビームの強さ。0 から 1、省略すると 0.6。 |

## 何が描かれるか

- **円すい。** 衛星から地面へ向かう、やわらかく透けた円すいです。衛星のそばが明るく、地面に近づくにつれて薄くなります。画面に光を足すので、夜の側でも昼の側でも見えます。地球の縁より向こう側は、ほかのものと同じように地球にかくれます。
- **地上の光の輪。** 地面に、輪と薄い塗りで描かれます。衛星が指定した仰角（省略すると 25 度）より上に見える地点の円で、表示している時刻の衛星の高さから計算します。地球の中心から見た角度は `acos(R cos(e) / (R + h)) - e` です。これが本当の大きさで、国際宇宙ステーション（ISS）では半径およそ 750 km、スターリンクの衛星では 940 km、静止衛星では 6,350 km です。`footprintAngle` と `footprintKm` は、同じ数字を単独で返します。
- **セル。** `beam-cells` を指定すると、その数のスポットセルが輪の中に、六角形に詰めた小さな輪として描かれ、それぞれに衛星から細い光の筋が伸びます。これは**イラスト**です。地面をセルで受け持つ衛星のようすを、輪の中に収まるように描いたもので、どの運用会社のビーム配置でもありません。数と大きさは、ページが指定したとおりです。

## 乗っているとき

「衛星に乗る」でも「衛星の上から見る」でも、乗っている衛星のビームが出ます。衛星から円すいの中を見下ろすと、真下の地面に光の輪が見えます。カメラのすぐそばでは円すいが薄くなるので、まぶしくなりません。

## ページから読めるもの

`stats.beam` は、直前の描画でビームを描いたか（`shown`）、衛星の高さ（`heightKm`）、地面に沿った光の輪の半径（`radiusKm`）と地球の中心から見た角度（`angleDegrees`）、計算に使った仰角、描いたセルの数（`cells`）とセルの半径（`cellRadiusKm`、km）、形を作った回数（`builds`）、作れなかったか（`failed`。渡された three.js に `AdditiveBlending` がないときは、要素が `chikyu-beam-unavailable` も送ります）を返します。

## 負担

ビームは、衛星を動かす描画の一部です。止まっているときは何も描かず、時計を止めているときも描きません。形は一度だけ作り（セルの数が変わるときだけ作り直し）、あとは数個の数字からグラフィックスカードの上で計算するので、時計が進んでも作り直しは起きません。ゆらぎ（きらめき）はなく、動きを減らしたい人にも同じ静止したビームが出ます。
